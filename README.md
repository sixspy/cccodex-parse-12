## 抽样抽检流程

解析 → **抽样抽检** → 落档。抽检不过或走法不符，落档一律被拦。

| 环节 | 规则 |
|------|------|
| 抽检策略 `/policy/` | 每日一条；抽检比例可钉死；失败走法当日唯一，可钉死 |
| 失败走法 | `整批挡住落档退回重析` 或 `放行落档但标待复核只读`，二选一 |
| 抽检 `/jobs/<id>/inspect/` | 后台裁定；按比例抽样，命中即失败；比例写成 0 直接失败 |
| 落档 `/jobs/<id>/land/` | 无抽检、抽检未过、走法偏离策略、零比例，全部拦下 |
| 争抢 | 同一轮次先到请求裁定，后到请求记「抽检争用失败」 |
| 抽检列表 `/inspections/` | 通过态 / 待复核态 / 挡住 / 争用失败分组；命中样例可展开 |
| 读盘详情 | 并排展示抽检条数、通过占比、待复核数、走法名 |

台账口径：`退回重析` 可重新解析生成新一轮；`待复核` 为只读，不再接受解析、抽检与落档。
